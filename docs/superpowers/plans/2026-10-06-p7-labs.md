**Goal:**

**Architecture:**
- **Lab là lesson:** `kind: 'lab'` dùng một enum riêng cho lesson, nên item không thể mang `kind: 'lab'`.
- **Tiêu đề:** lấy từ dòng `# …` đầu tiên của thân bài. Lesson và Library hiện tiêu đề này; thân bài bỏ dòng đó.

- [ ] **Step 3: Tạo `src/content/labs.ts`**

```ts
import type { Lesson } from '../core/schema';

const H1 = /^#\s+(.+?)\s*$/;

/** A lesson may open with `# Title`. Labs do, since one topic can have several. */
export function splitTitle(body: string): { title?: string; rest: string } {
  const lines = body.replace(/\r\n/g, '\n').split('\n');
  const first = lines.findIndex((line) => line.trim() !== '');
  const match = first === -1 ? null : H1.exec(lines[first].trim());
  if (!match) return { rest: body };
  return { title: match[1], rest: lines.slice(first + 1).join('\n') };
}

/** The labs among a question's lessons, in the question's order. */
export function labsFor(lessonIds: string[], lessons: Lesson[]): Lesson[] {
  const byId = new Map(lessons.map((l) => [l.id, l]));
  return lessonIds.flatMap((id) => {
    const lesson = byId.get(id);
    return lesson?.kind === 'lab' ? [lesson] : [];
  });
}
```

- [ ] **Step 8: Tạo `src/screens/questions/VerifyLinks.tsx`**

```tsx
import { href } from '../../app/router';
import { labsFor, splitTitle } from '../../content/labs';
import type { Content } from '../../content/load';
import { useLang } from '../../i18n/LangProvider';

/** "How to verify" links to the labs a question points at; nothing when it has none. */
export function VerifyLinks({ lessonIds, content }: { lessonIds: string[]; content: Content }) {
  const { t, pick } = useLang();
  const labs = labsFor(lessonIds, content.lessons);
  if (labs.length === 0) return null;
  return (
    <div className="stack" style={{ gap: 'var(--space-1)' }}>
      {labs.map((l) => (
        <a key={l.id} href={href({ name: 'lesson', lessonId: l.id })}>
          {t('verifyLink', { title: splitTitle(pick(l.body)).title ?? l.id })}
        </a>
      ))}
    </div>
  );
}
```

Challenge ngược: người học viết **phần kiểm tra**, không viết phần cài đặt. Code của người học chỉ có `console` trong scope (không có `expect`), nên phần kiểm tra là một hàm tự ném lỗi.

- **Đề:** cho kiểu và mô tả của một reducer giỏ hàng:
  - `cartReducer(state, action)`, với `CartState = { items: { id: string; qty: number; price: number }[] }`.
  - Các action: `add` (thêm 1, hoặc tăng `qty` nếu đã có), `remove` (xoá hẳn), `setQty` (`qty <= 0` thì xoá).
  - Không được sửa state cũ.
  - `cartTotal(state)` trả về tổng `qty * price`.

  Người học viết `export function verifyCart(cartReducer: Reducer, cartTotal: Total): void`, hàm này ném `Error` khi cài đặt sai.
- **`tests.ts`:**
  - Một test `basic`: cài đặt đúng thì `verifyCart` không ném.
  - Các test `hidden`, mỗi test truyền một bản cài đặt có đúng một lỗi và kỳ vọng `verifyCart` ném. Có ít nhất 5 bản lỗi:
    - `add` thêm dòng mới thay vì tăng `qty`
    - `remove` chỉ giảm `qty`
    - `setQty(0)` giữ lại dòng
    - reducer sửa state cũ thay vì trả state mới
    - `cartTotal` bỏ qua `qty`
  - Có ít nhất 2 test `hidden`, category theo guide (`basic`, `edge-case`).
- **`starter.ts`:** `verifyCart` rỗng. Nó pass test cài đặt đúng nhưng fail mọi bản lỗi, nên đúng quy tắc "starter phải fail ít nhất một test".
- **`solution.ts`:** một `verifyCart` bắt được cả 5 lỗi, viết bằng vài hàm `assert` nhỏ tự định nghĩa.
- **`meta.json`:** `topics: ["testing/unit"]`, `kind: "core"`, `difficulty: 2`, `estSeconds: 600`, `lessons: ["testing-unit-core"]`, 2 hint.
- **`prompt.{vi,en}.md`** theo khung của challenge có sẵn (`content/challenges/event-emitter/`). Thêm một mục giải thích vì sao viết kiểm tra như vậy chính là viết unit test: mỗi lỗi phải có một kiểm tra bắt được nó.

- [ ] **Checkpoint (Warren):** `npx vitest run src/content/content.test.ts`. Kỳ vọng: solution của `cart-checks` pass mọi test, starter fail ít nhất một.
